📊 Proyecto Hackathon – Análisis y Predicción de Churn

Este repositorio contiene el trabajo del equipo de Data Science para el análisis y modelado del churn de clientes durante la hackathon.

El enfoque principal del proyecto es el análisis de datos, la construcción del modelo de churn y la documentación técnica necesaria para su comprensión e integración.

🎯 Objetivo

Analizar el comportamiento de los clientes y construir un modelo de Machine Learning capaz de estimar la probabilidad de abandono (churn) a partir de variables demográficas, contractuales, de servicios y de facturación.

🧠 Modelado de datos

Modelo físico de datos diseñado en MySQL Workbench para representar la estructura relacional asociada al dominio de churn.

Modelo conceptual que describe las entidades principales del negocio (Clientes, Servicios, Contratos, Pagos) y sus relaciones.

🔁 Flujo de predicción

Diagrama_Flujo_Prediccion_Churn.drawio
Diagrama de flujo que representa el proceso de predicción de churn, desde el envío de datos del cliente hasta la obtención de la respuesta con la probabilidad de abandono.

🗺️ Roadmap de Análisis de Churn

El roadmap describe el flujo del análisis orientado a reducir la tasa de abandono de clientes, partiendo del objetivo del negocio, el entendimiento y modelado de los datos, su limpieza y análisis, la visualización de resultados en Power BI y la toma de decisiones, incorporando un proceso de mejora continua mediante monitoreo y ajustes.

🧪 Enfoque del modelo

El modelo desarrollado tiene como objetivo principal detectar clientes con mayor riesgo de abandono, priorizando métricas relevantes para la clase positiva (churn) y manteniendo coherencia con el contexto del problema de negocio.

🤝 Contexto

Este repositorio forma parte del trabajo colaborativo realizado durante la hackathon y documenta el proceso completo de análisis y modelado de churn desde la perspectiva de Data Science.
